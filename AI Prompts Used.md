# &#x20;AI Prompts Used



\## Project Overview



This project demonstrates how Generative AI was integrated throughout the complete analytics lifecycle—from business understanding and SQL analysis to Python EDA, Power BI dashboard development, and executive reporting.



\---



\# Prompt 1 – Business Understanding (ChatGPT)



\## Prompt



Act as a Senior Business Analyst and Data Analyst.



I am building an AI-Augmented Customer Shopping Trends Analysis project using the Shopping Trends dataset containing 3,900 customer records and 18 attributes.



Analyze the dataset and prepare a complete Business Understanding document including:



\- Business Overview

\- Dataset Summary

\- Business Objectives

\- Stakeholders

\- Important Dataset Features

\- Business Questions

\- Key Performance Indicators (KPIs)

\- Dataset Limitations



The content should be professional, suitable for a GitHub project, executive report, and Power BI portfolio.

\# Prompt 2 – SQL Database Design (ChatGPT)



\## Prompt



Using the Shopping Trends dataset, generate a PostgreSQL CREATE TABLE statement with appropriate data types.



Requirements:

\- Use snake\_case column names.

\- Keep Customer ID from the dataset (do not generate SERIAL).

\- Add comments explaining each column.

\- Follow SQL best practices.
